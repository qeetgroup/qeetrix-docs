### Keyboard

<kbd>Tab</kbd> <kbd>Shift+tab</kbd> <kbd>Escape</kbd>

### Focus

Each control is a Tab stop, in order. While open, focus is contained and focus returns on close.

### Known limitations

- **Focus:** Focus containment is enforced with `inert`, which jsdom does not implement, so the tests assert the mechanism is installed rather than observing containment. Browser-level verification is on the manual checklist.
