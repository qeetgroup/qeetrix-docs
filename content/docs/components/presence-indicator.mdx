## Examples

### Default

Each state has its own shape — a disc, a crescent, a barred disc and a ring — so presence never rests on green versus red. The mark is announced by its status, or by `label`.

<ComponentPreview name="presence-indicator/1-default" />

### On avatar

On an avatar, the ring and the cut-outs are painted in `--presence-surface`, which defaults to the page background. Set it to the surface underneath, here `--card`. `pulse` adds a soft pulse that stops under reduced motion.

<ComponentPreview name="presence-indicator/2-on-avatar" />
