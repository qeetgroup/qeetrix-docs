## Accessibility

Follows the WAI-ARIA `dialog` pattern. Not yet audited.

**Keyboard:** <kbd>Tab</kbd> <kbd>Shift+tab</kbd> <kbd>Escape</kbd> <kbd>ArrowLeft</kbd> <kbd>ArrowRight</kbd>

**Focus:** Each control is a Tab stop, in order. While open, focus is contained and focus returns on close.
