## Examples

### Default

An inline note in the flow of the page, with an accent rule and an icon. It is static: a `role="note"`, not a live region, and not dismissible (use Alert for that).

<ComponentPreview name="callout/1-default" />

### Variants

`variant` sets the accent, the default icon and the title colour. `muted` is a neutral note with a graphite accent; `title` is optional.
