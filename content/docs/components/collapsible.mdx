## Examples

### Default

A disclosure for secondary content: the recovery codes stay hidden until asked for. The trigger is unstyled, so here it renders as a `Button` (`render={<Button />}`), and its `data-panel-open` attribute swaps the label and turns the chevron.

<ComponentPreview name="collapsible/1-default" />

### Advanced options

Rarely changed fields fold away under a text trigger, below the fields everyone needs. The panel starts closed; pass `defaultOpen` to start it open.

## Usage

### Import

```tsx
import { Collapsible } from "@qeetrix/ui";
```

It can also be imported on its own from `@qeetrix/ui/components/collapsible`.

### Controlled and uncontrolled

Pass the value prop to control it, or the default prop to let the component own it.

| Value | Default | Change |
| --- | --- | --- |
| `open` | `defaultOpen` | `onOpenChange` |

### States

`open`
