## Examples

### Default

Hovering or focusing the link shows who is behind it. Hover cards don't open on touch, so they only add detail: anything a user needs in order to act belongs on the page or in a Popover.

## Usage

### Import

```tsx
import { HoverCard } from "@qeetrix/ui";
```

It can also be imported on its own from `@qeetrix/ui/components/hover-card`.

### Controlled and uncontrolled

Pass the value prop to control it, or the default prop to let the component own it.

| Value | Default | Change |
| --- | --- | --- |
| `open` | `defaultOpen` | `onOpenChange` |
