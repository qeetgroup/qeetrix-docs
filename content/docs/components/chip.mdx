## Examples

### Default

A `ChipGroup` is single-select by default: a radio group with one tab stop, where the arrow keys move the selection. The selected chip shows a check mark, so selection never rests on colour alone.

<ComponentPreview name="chip/1-default" />

### Multiple

`multiple` turns the chips into independent toggle buttons, each its own tab stop.

<ComponentPreview name="chip/2-multiple" />

### Removable

`onRemove` adds a × button for applied values such as these office locations. Its accessible name is "Remove" by default; override it per chip through `messages` so each button says what it removes.

<ComponentPreview name="chip/3-removable" />
