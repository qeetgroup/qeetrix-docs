## Accessibility

Follows the WAI-ARIA `spinbutton` pattern. Not yet audited.

### Keyboard

<kbd>Tab</kbd> <kbd>ArrowUp</kbd> <kbd>ArrowDown</kbd>

### Focus

Each control is a Tab stop, in order.

### Known limitations

- **Semantics:** Base UI renders a text input with aria-roledescription ("Number field") rather than role=spinbutton; the spinbutton keyboard contract (ArrowUp/ArrowDown step) holds. The role description comes from the catalogue (numberField.roleDescription).
