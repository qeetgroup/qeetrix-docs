## Examples

### Default

`ChartContainer` themes a Recharts chart you compose yourself. Each `config` entry names a series and, unless it sets a `color`, takes the categorical colour for its position in the config, as `--color-<key>`. The tooltip and legend content read their labels from it too.

<ComponentPreview name="chart/1-default" />

### Data table

`accessibilityTable` takes a native table of the plotted data, usually a `ChartDataTable`. It is screen-reader-only by default; `accessibilityTableVisibility="visible"` shows it below the plot.

<ComponentPreview name="chart/2-data-table" />

## Usage

### Import

```tsx
import {
  ChartContainer,
  ChartDataTable,
  ChartLegend,
  ChartLegendContent,
  ChartStyle,
  ChartTooltip,
  ChartTooltipContent,
} from "@qeetrix/ui";
```

It can also be imported on its own from `@qeetrix/ui/components/chart`.
