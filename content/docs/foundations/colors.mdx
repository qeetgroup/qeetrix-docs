Build with the semantic roles. Each one has a meaning and a value for each theme, and every text
and surface pair the roles are designed for meets WCAG AA contrast. Colour is authored in OKLCH.

The **Tailwind** column gives each colour's utility with `bg-`; the same name works with `text-`,
`border-` and the other colour utilities. Roles without a utility of their own are used through the
variable.
