## For tools

- **The component manifest** — `@qeetrix/ui/manifest.json` describes every component: status, capabilities, states, API and accessibility. Import it from the package.
- **The design tokens** — `@qeetrix/ui/tokens.json` resolves every token for the light and dark themes.
- **These docs as text** — [/llms.txt](/llms.txt) indexes every page, and [/llms-full.txt](/llms-full.txt) is the whole site in one file.

The Storybook workshop (`qeetrix-story`) is internal and not publicly deployed.
