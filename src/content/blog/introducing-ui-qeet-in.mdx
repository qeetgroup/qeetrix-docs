Qeetrix has been real for a while — 116 accessible components, a fully tokenised OKLCH design language, and a WCAG-AA-gated build, live across the Qeet Group suite. What it lacked was a home. Today it has one: **ui.qeet.in**.

## One place for humans and machines

ui.qeet.in is the operating surface of the design system. Browse every component with live previews and auto-generated props, explore design tokens, tune a theme visually, and copy code that actually runs — all built on `@qeetrix/ui` itself.

It also treats machines as first-class readers. There's an `llms.txt` index, a shadcn-compatible registry at `/r/*`, and a remote MCP server at `/mcp` so AI coding agents emit correct Qeetrix code instead of guessing.

## Built on Qeetrix

The whole site dogfoods `@qeetrix/ui` — if it's fast, accessible, and unmistakably Qeet, that *is* the pitch.

```bash
npx qeetrix init
```

Head to the [components catalogue](/components), open the [Playground](/play), or wire an agent to the [MCP server](/develop/mcp).
