Qeetrix is the design system of Qeet Group. Its components are accessible and token-driven,
built on Base UI and made for the consoles and products of Qeet Group — in English and Hindi,
light and dark, left to right and right to left.

| Package | Version | What it is |
| --- | --- | --- |
| `@qeetrix/react` | <Badge tone="info" size="sm">0.1.1</Badge> | The React components |
| `@qeetrix/tokens` | <Badge tone="info" size="sm">0.0.9</Badge> | Design tokens: CSS variables, DTCG files, `brandTheme()` for a tenant's colour |
| `@qeetrix/icons` | <Badge tone="info" size="sm">1.0.12</Badge> | Icons in round and sharp, and the Qeet logos |
